# ⚽ Olho no Lance

**Olho no Lance** é uma plataforma de scouting e gerenciamento de informações voltada ao mercado de transferências de jogadores de futebol.

O sistema tem como objetivo centralizar informações relevantes sobre atletas e clubes, auxiliando na análise de jogadores e na tomada de decisão durante processos de prospecção, negociação e transferência.

## 🎯 Objetivo

A proposta do projeto é funcionar como uma espécie de **“super olheiro”**, reunindo em um único sistema informações esportivas, físicas, financeiras e contratuais dos jogadores.

Entre as informações previstas estão:

* Dados pessoais e características físicas dos jogadores;
* Clubes e vínculos contratuais;
* Posições em campo;
* Valor de mercado;
* Avaliações técnicas dos atletas;
* Histórico de avaliações;
* Interesse de clubes em jogadores;
* Negociações;
* Transferências entre clubes.

## 📊 Avaliação dos jogadores

Os jogadores poderão possuir avaliações técnicas realizadas em diferentes momentos.

As avaliações serão baseadas em seis características principais:

* Velocidade;
* Finalização;
* Passe;
* Drible;
* Defesa;
* Físico.

Essas informações poderão futuramente ser utilizadas pela aplicação para gerar uma representação gráfica do perfil esportivo de cada jogador.

## 🗃️ Principais entidades

Inicialmente, o domínio considera entidades como:

* **Jogador**
* **Clube**
* **Contrato**
* **Posição**
* **Avaliação**
* **Negociação**
* **Transferência**

A estrutura poderá ser refinada durante o processo de modelagem do banco de dados.

## 🚧 Status do projeto

O projeto encontra-se atualmente em fase de **levantamento de requisitos e modelagem do domínio**.

As próximas etapas incluem:
